# 02. 환경 설정과 첫 배포

목표: 빈 폴더에서 시작해 **인터넷에 접속되는 주소**를 만드는 것까지.
여기까지 되면 나머지는 그 위에 얹는 일이다.

---

## 준비물

| | 무엇 | 확인 방법 |
|---|---|---|
| 1 | **Node.js** (버전 20 이상) | `node --version` |
| 2 | **Cloudflare 계정** (무료) | https://dash.cloudflare.com 가입 |
| 3 | 코드 편집기 | VS Code 등 |
| 4 | **git** (선택이지만 권장) | `git --version` |

Node.js는 https://nodejs.org 에서 LTS 버전을 받으면 된다. Node를 설치하면
`npm`과 `npx`가 같이 깔린다.

> **npm과 npx 차이**: `npm`은 패키지를 설치·관리하고, `npx`는 설치된(또는 임시로
> 받아온) 도구를 **실행**한다. 이 프로젝트에서 `npx wrangler ...`를 쓰는 이유는
> wrangler를 전역 설치하지 않고 프로젝트에 묶어 두기 위해서다 — 프로젝트마다
> 버전이 달라도 서로 간섭하지 않는다.

## 1. 프로젝트 폴더 만들기

```bash
mkdir my-webapp
cd my-webapp
npm init -y
npm install --save-dev wrangler
```

`--save-dev`는 "개발할 때만 필요한 도구"라는 표시다. 실제 배포되는 코드에는
들어가지 않는다.

## 2. 폴더 구조 잡기

```
my-webapp/
  public/            ← 브라우저로 그대로 내려갈 파일
    index.html
  src/
    worker.js        ← 서버 코드 (지금은 거의 비어 있어도 된다)
  wrangler.jsonc     ← 배포 설정
  package.json
```

```bash
mkdir public src
```

## 3. 설정 파일 (wrangler.jsonc)

가장 작은 형태부터 시작한다.

```jsonc
{
  "name": "my-webapp",
  "main": "src/worker.js",
  "compatibility_date": "2025-09-01",
  "assets": {
    "directory": "./public",
    "binding": "ASSETS",
    "not_found_handling": "single-page-application",
    "run_worker_first": ["/api/*"]
  }
}
```

각 항목의 뜻:

| 항목 | 뜻 |
|---|---|
| `name` | 배포될 이름. 주소가 `https://<name>.<계정>.workers.dev`가 된다 |
| `main` | 서버 코드 진입 파일 |
| `compatibility_date` | 이 날짜 기준의 Workers 동작 방식을 쓴다. 한 번 정하면 그대로 두는 게 안전하다 |
| `assets.directory` | 정적 파일 폴더 |
| `assets.binding` | 코드에서 `env.ASSETS`로 접근할 이름 |
| `not_found_handling` | 없는 주소일 때 처리. `single-page-application`은 `index.html`을 준다 |
| `run_worker_first` | 이 패턴만 서버 코드로 보낸다. 나머지는 정적 파일로 바로 서빙 |

**`run_worker_first`가 왜 중요한가**: 이게 없으면 모든 요청이 서버 코드를 거친다.
이미지 하나 받는 것도 서버를 깨우게 되고, 그만큼 요청 수를 쓴다. `/api/*`만
서버로 보내면 나머지는 Cloudflare가 알아서 빠르게 내려준다.

## 4. 최소 파일 두 개

`public/index.html`:

```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>내 웹앱</title>
</head>
<body>
  <h1>안녕</h1>
  <div id="app"></div>
</body>
</html>
```

> `<meta name="viewport" ...>`는 모바일에서 화면을 제대로 보이게 하는 필수 줄이다.
> 빼먹으면 휴대폰에서 데스크톱 화면이 축소돼 보인다.

`src/worker.js`:

```js
export default {
  async fetch(request, env, ctx){
    const url = new URL(request.url);

    if (url.pathname === "/api/hello"){
      return Response.json({ message: "안녕", now: new Date().toISOString() });
    }

    // /api/* 외에는 여기 오지 않지만, 방어적으로 정적 파일 폴백을 둔다
    return env.ASSETS.fetch(request);
  },
};
```

이 구조를 기억하면 된다. **`fetch`는 요청이 올 때마다 불리는 함수**이고,
`request`(요청), `env`(자원들), `ctx`(부가 기능)를 받아 `Response`를 돌려준다.

## 5. 로컬에서 실행

```bash
npx wrangler dev
```

`http://127.0.0.1:8787`이 열린다. 브라우저로 접속하면 `index.html`이 보이고,
`http://127.0.0.1:8787/api/hello`로 가면 JSON이 보인다.

**첫 실행이라면 로그인을 요구할 수 있다.** 브라우저가 열리고 Cloudflare 계정
연결을 물어보면 승인하면 된다.

편의를 위해 `package.json`에 스크립트를 넣어두자.

```json
{
  "scripts": {
    "dev": "wrangler dev",
    "deploy": "wrangler deploy",
    "tail": "wrangler tail"
  }
}
```

이제 `npm run dev`로 실행된다.

## 6. 배포

```bash
npx wrangler deploy
```

끝나면 주소가 출력된다.

```
Deployed my-webapp triggers
  https://my-webapp.<계정이름>.workers.dev
Current Version ID: 1a2b3c4d-...
```

그 주소로 접속되면 성공이다. **Version ID를 메모해 두는 습관을 들이면 좋다** —
문제가 생겼을 때 이 버전으로 되돌릴 수 있다.
→ [10번 문서](./10-운영-런북.md#배포-되돌리기)

## 7. git 으로 이력 남기기 (권장)

```bash
git init
git add .
git commit -m "첫 배포"
```

`.gitignore` 파일을 만들어 아래를 넣는다. **비밀키와 빌드 부산물이 올라가면
안 된다.**

```
node_modules/
.wrangler/
.dev.vars
.DS_Store
```

`.dev.vars`는 로컬 비밀키 파일이다(다음 문서에서 나온다). 이걸 커밋하면 인증키가
저장소에 영구히 남는다 — **한 번 커밋되면 파일을 지워도 히스토리에 남는다.**

## 자주 겪는 문제

**`wrangler: command not found`**
`npx`를 붙였는지 확인한다. `npx wrangler ...`

**배포는 됐는데 주소가 404**
`public/index.html`이 있는지, `wrangler.jsonc`의 `assets.directory`가
`"./public"`인지 확인한다.

**`/api/hello`가 JSON 대신 HTML(index.html)을 준다**
`run_worker_first`에 `"/api/*"`가 있는지 확인한다. 없으면 정적 에셋의 SPA
폴백이 먼저 삼켜 버린다.

**수정했는데 화면이 안 바뀐다**
브라우저 캐시다. 강제 새로고침(`Ctrl+Shift+R`)을 하거나 개발자 도구
Network 탭에서 "Disable cache"를 켠다.

**`compatibility_date`가 미래 날짜라고 경고**
오늘 이전 날짜로 바꾼다.

## 이 저장소와 비교해 보기

지금 만든 것과 이 저장소의 차이는 "그 위에 얹은 것들"뿐이다.

| 지금 만든 것 | 이 저장소가 추가한 것 |
|---|---|
| `wrangler.jsonc` 최소 설정 | D1·AI·Cron 바인딩 추가 |
| `index.html` 한 장 | CSS·JS 모듈 분리, 라우팅 |
| `/api/hello` | `/api/*` 여섯 개 엔드포인트 |
